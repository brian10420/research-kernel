# Presentation Log

One row per audience-facing artifact (deck, poster, one-pager). The
`science-presenter` skill appends a row on every delivery — newest first.

| Date | Topic | Audience | Medium | Language | Artifact URL / file | Sources verified |
| ---- | ----- | -------- | ------ | -------- | ------------------- | ---------------- |

Conventions:

- Deck HTML sources live at `<deck-source-dir>/<date>-<topic>.html` (tracked);
  posters/graphical abstracts live as design-canvas artifacts (the URL here is
  the record).
- **Sources verified** = date of the pre-flight scan that confirmed every
  embedded figure/number file existed on disk (skill contract step 3).
- Numbers on slides obey the honesty rail: guard phrasings kept verbatim,
  every number with its uncertainty — simplification may omit, never inflate.
