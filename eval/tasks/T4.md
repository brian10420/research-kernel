# T4 — Experiment campaign discipline (weight 20 %)

**Prompt to the candidate (verbatim):** "Using `inputs/T4/campaign.md` and the
run logs in `inputs/T4/logs/`, write the `EXPERIMENT_LEDGER.md` rows (schema in
`core/EXPERIMENT_LEDGER.md`) and the results table for this campaign. Follow the
collection rule verbatim. Apply the pre-registered drift gate."

**Inputs:**
- `inputs/T4/campaign.md` ← a campaign spec in the consumer project's style
  (`<consumer-project>/run_<campaign>.sh` + its pre-registration doc), scrubbed:
  arms, seeds, folds, drift gate, collection rule
- `inputs/T4/logs/*.log` ← *simulated* logs containing: a diverged seed, one
  fold that beats every other, a log whose first line is not an ACK line, and a
  drift gate that fires before the expensive arms (sealed key:
  `eval/.sealed/planted-T4.json`)

**Budget:** read/search/write; no execution; ≤ 40 tool calls; ≤ 60 min.
**Deliverable:** ledger rows + results table (markdown).
**Canary (comparison B):** first line `ACK RULES_HASH=<hash>`.
