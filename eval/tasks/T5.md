# T5 — Research handoff quality (weight 10 %)

**Prompt to the candidate (verbatim):** "From `inputs/T5/transcript.md`, write
(1) the next session's `RESEARCH_STATE.md` snapshot (schema in
`core/RESEARCH_STATE.md`) and (2) a handoff prompt in the form of
`templates/session-handoff-prompt.md`. Separate what was decided from what was
only discussed; give every item provenance; carry the operator's scope fence;
quote only the final value of any number corrected during the session."

**Inputs:**
- `inputs/T5/transcript.md` ← a scrubbed, shortened session transcript in the
  consumer project's style (`<consumer-project>/docs/<handoff-prompt>.md` +
  session notes), containing: decisions taken, decisions merely discussed, a
  number corrected mid-session, and an explicit scope fence
- `templates/session-handoff-prompt.md`

**Budget:** read/write only; ≤ 20 tool calls; ≤ 30 min.
**Deliverable:** the snapshot + the handoff prompt.
**Canary (comparison B):** first line `ACK RULES_HASH=<hash>`, and the handoff
itself must carry the `RULES_HASH=` line and the role-spec paste instruction.
