# T2 — Pleasure–Arousal–Dominance boundary research loop (weight 30 %)

**Prompt to the candidate (verbatim):** "Read the state files in
`inputs/T2/state/` and the question in `inputs/T2/question.md`. Propose ONE
`HYPOTHESES.md` entry (schema in `core/HYPOTHESES.md`) that answers it: a
falsifiable statement, prediction, falsifier, pre-registered decision rule, and
the smallest decisive experiment with a cost estimate sized to the resources
stated in `RESEARCH_STATE.md`. Verify the load-bearing literature claims (mark
each verified/unverified with how). Check `FAILED_IDEAS.md` before proposing."

**Inputs:**
- `inputs/T2/state/RESEARCH_STATE.md`, `HYPOTHESES.md`, `FAILED_IDEAS.md`,
  `OPEN_QUESTIONS.md`, `LITERATURE_MAP.md` ← excerpts of the consumer project's
  state, scrubbed (`<consumer-project>/project-state/*.md`)
- `inputs/T2/papers/*.pdf` ← 3–5 papers on joint-plane affect modeling
- `inputs/T2/question.md` ← the boundary question (which plane pairs are
  modeled jointly; which head owns which claim), including the **trap**: a
  tempting idea already refuted in `FAILED_IDEAS.md`

**Budget:** read/search (+ web if the condition provides it); ≤ 60 tool calls;
≤ 90 min.
**Deliverable:** the hypothesis entry + literature-map entries + a one-page
recommendation.
**Canary (comparison B):** first line `ACK RULES_HASH=<hash>`.
